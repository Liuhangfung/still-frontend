Can every task have its own art? Yes.

Still's content is fixed and versioned: the same 56 quests in the same order for everyone, with only the coach's voice changing. So we can draw the whole set once, check every image before release and ship it like any other content. Nothing is generated while the user is in the app.

What gets art

Main quests (Days 1–56, incl. gates and 4 chapter bosses)56
Daily sub-task stamps (same image every day)7
Chapter covers (shown when a chapter unlocks)4
Recovery Quest stamp (after a missed day)1
Total to draw~68

Plan 3–4 drafts each to choose from, so about 250 generations. Lines from the Sergeant and the System share the same art.

Keeping the style consistent

  • One style guide prompt for every image: Araki-style heavy inking, cross-hatching, speed lines, dramatic low angles, palette locked to teal #0FA3A3 / dark teal / gold #FFC300 / ink.
  • Reference images: the 3 approved blog pieces go into every generation as style references.
  • A recurring cast: "the Hunter" (the user, often seen from behind so anyone can picture themselves), plus the System and the Sergeant. The same faces across 56 days make it feel like one story.
  • One composition rule: keep the subject in the centre 60%, so one 4:5 master crops cleanly to the 16:9 card, the square tile and the share card.

How it ships

  • Each quest's content gets an art_key (e.g. q-c1-10). The API returns it with the quest. The art is part of the content, not user data.
  • Stored as WebP at 2 sizes (~640px and ~1080px), around 100–200 KB each. The full set is ~20 MB on a CDN, not inside the app download.
  • The app downloads the next 2 days' art ahead of time, so the briefing never shows an empty panel. Locked days use a tiny blurred preview.
  • Changing a quest's art = new image + new art_key. Nothing about the user's progress changes.

Rules for the art

  • No green "up" charts as a reward, no piles of money, no lambos. Gold means discipline, not profit.
  • Charts in the art show the trap (FOMO, revenge) and never a coin logo or ticker.
  • No real people, no real exchange branding, no copies of actual JoJo characters or poses. Same style, our own characters.
  • Calm mode hides all art (screen F). The art should also never make a loss look exciting.
