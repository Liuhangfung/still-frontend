STILL: UI design v3 · Chapter themes

Each chapter is its own JoJo-style "part", with its own setting, time of day and colours, moving from midnight to golden hour as the user goes from chaos to calm. The theme changes the background, panels, accents, halftone and the colour grading of the art. What never changes: gold for the next action, black ink outlines, coral for "stop and think", and calm mode on safety screens. Art is still placeholder (the blog pieces, recoloured per chapter).

What stays the same in every chapter

Fixed meaning colours

  • Gold #FFC300: one main button per screen, XP and rewards. Same in all 4 chapters.
  • Ink #111111: outlines and hard comic shadows.
  • Coral #FF5A4E: only "Not today" and warnings. No chapter accent is red, green or coral.
  • Calm mode (safety screens) stays teal and white in every chapter, with no art.

What the chapter changes

  • Background, panels, tab bar and deep shadow.
  • Accent colour: eyebrows, progress bars, selected chips, speed lines, halftone dots, card shadows.
  • Art: setting, time of day and colour grading.
  • The JoJo sound effect used on that chapter's quest art.

How the app does it

The app keeps one set of colour names and swaps their values by chapter. Nothing else in the code needs to know which chapter it is in.

[data-chapter="2"] {        /* Violet Blueprint */
  --still-bg:#1E1238; --still-panel:#2A1B4D;
  --still-accent:#9B6BFF; --still-accent-dark:#3E2780;
  --still-text-muted:#B9A9DD;
  --still-gold:#FFC300;     /* never changes */
}
