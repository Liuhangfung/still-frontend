      Why it changes

      Tools read like old homework: a grid of titles, and the words were one tap away. Notes puts the words on the page and orders them by the moment each is for, the way the programme uses them: read before you trade, followed when the urge comes, kept as rules, compared against later.

      What is on the page
      • Before you trade: the Trader Code (use read), in full, with where it is asked.
      • When the urge comes: the Urge Plan (use run). Following it records taps and how it ended, never a trade.
      • Rules you keep: every rule as one sentence, When …, I …, with the daily check that asks about it.
      • Where you started: reference records as index cards. Locked ones wait for their day.
      • Written by you: notes the user writes themselves.
      The rename
      • The tab, the heading and the dock say Notes. "Tool" stays in the docs and the API (/v1/inventory), so nothing on the server changes.
      • Counts of follows are plain counts. No streaks, and a missed follow is not a broken one.
